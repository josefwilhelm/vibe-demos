# vibe-demos

Kleine, echte Demos zu den Artikeln auf [einfachvibecoden.com](https://einfachvibecoden.com).

Jeder Ordner gehört zu einem Artikel. Die Demos sind mit KI-Werkzeugen gebaut (meist Claude Code), genau aus dem Prompt, der im Artikel steht. Die Screenshots im Artikel stammen aus diesen Demos. In `demo.json` steht jeweils, womit, wann und mit welchen Nachbesserungen die Demo entstanden ist.

| Ordner | Artikel |
|---|---|
| [`preisrechner-reinigung`](preisrechner-reinigung) | [Vibe Coding Beispiele](https://einfachvibecoden.com/blog/vibe-coding-beispiele) |
| [`website-blumenladen`](website-blumenladen) | [Beste KI, um eine Website zu erstellen](https://einfachvibecoden.com/blog/beste-ki-website-erstellen) |
| [`fotostudio-anfrage-app`](fotostudio-anfrage-app) | [App erstellen ohne Programmieren](https://einfachvibecoden.com/blog/app-erstellen-ohne-programmieren) |
| [`claude-code-cafe-landing`](claude-code-cafe-landing) | [Claude Code vs. Lovable](https://einfachvibecoden.com/blog/claude-code-vs-lovable) |

Preise und Daten in den Demos sind Beispielwerte.
